Features

Everything for your first iPhone app

iOS development on Windows without the hassle: an editor, the Swift compiler, an iPhone simulator, SwiftUI previews and a debugger in one app that looks and works like Xcode.

iPhone simulator

Six models: iPhone 16 Pro, 16 Pro Max, 16, 16 Plus, 16e and SE. Mouse touch, gestures, light and dark mode, GPS location, language and permissions.

Live previews

The Canvas renders #Preview next to your code and refreshes as you type — just like SwiftUI previews in Xcode.

LLDB debugger

Click a line number to set a breakpoint, step with F6/F7/F8, inspect variables, the call stack and the (lldb) console with po.

Completion & live issues

SourceKit-LSP: code completion, Quick Help, Rename, Code Actions and one-click fix-its, with errors highlighted while you type.

SwiftUI on Windows

An open implementation of SwiftUI for Windows runs your code in the simulator without a Mac. Supported, among others:

  • NavigationStack, List, Form, TabView, ScrollView, grids and stacks
  • @State, @Binding, @Observable, @AppStorage, @Environment
  • alerts, sheets, menus, gestures, animations, images and SF Symbols
  • Localizable, String Catalog, Asset Catalog, CoreLocation and Combine

Feels like Xcode

Navigators, inspectors, a Library with SF Symbols, Edit Scheme, Open Quickly and familiar shortcuts (Cmd becomes Ctrl).

One-click setup

An installer without admin rights, and the Swift toolchain is one click away with Install Swift… — the app checks for updates on its own.

Themes & shortcuts

Light and dark appearance, editor themes, fonts and custom key bindings — all in Settings (Ctrl+,).

Up and running in minutes

How to start iOS development on Windows

Three steps — no Mac, no developer account, no terminal setup.

Download and install

Run WinSwift-Studio-Setup.exe and click Next → Install. No administrator rights needed — shortcuts appear on the desktop and in the Start menu.

Install Swift in one click

On first launch click the Install Swift… button — the app installs the Swift toolchain and Visual Studio Build Tools (Windows asks for approval once).

New project → Ctrl+R

Create New Project → iOS → App and press Ctrl+R. Your app launches in the iPhone simulator (the first run takes 1–2 minutes).

Windows says “Windows protected your PC”? Click “More info” → “Run anyway”. The app is free and not signed with a paid certificate; its source code is public on GitHub.
