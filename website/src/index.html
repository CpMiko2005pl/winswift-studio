Wszystko do pierwszej aplikacji na iPhone'a

Programowanie iOS na Windows bez kombinowania: edytor, kompilator Swift, symulator iPhone'a, podgląd SwiftUI i debugger w jednym programie, który wygląda i działa jak Xcode.

Symulator iPhone'a

Sześć modeli: iPhone 16 Pro, 16 Pro Max, 16, 16 Plus, 16e i SE. Dotyk myszą, gesty, tryb jasny i ciemny, lokalizacja GPS, język i uprawnienia.

Podgląd na żywo

Canvas pokazuje #Preview obok kodu i odświeża się w trakcie pisania — dokładnie jak podgląd SwiftUI w Xcode.

Debugger LLDB

Breakpointy kliknięciem w numer linii, krokowanie F6/F7/F8, podgląd zmiennych, stos wywołań i konsola (lldb) z po.

Podpowiedzi i błędy na żywo

SourceKit-LSP: autouzupełnianie, Quick Help, Rename, Code Actions i poprawki jednym kliknięciem, błędy podkreślane w trakcie pisania.

SwiftUI na Windows

Otwarta implementacja SwiftUI dla Windows sprawia, że Twój kod działa w symulatorze bez Maca. Obsługiwane m.in.:

  • NavigationStack, List, Form, TabView, ScrollView, siatki i stosy
  • @State, @Binding, @Observable, @AppStorage, @Environment
  • alerty, arkusze, menu, gesty, animacje, obrazy i SF Symbols
  • Localizable, String Catalog, Asset Catalog, CoreLocation i Combine

Interfejs jak w Xcode

Nawigatory, inspektory, Library z SF Symbols, Edit Scheme, Open Quickly i znajome skróty (Cmd zamienione na Ctrl).

Instalacja jednym kliknięciem

Instalator bez uprawnień administratora, a kompilator Swift dodasz przyciskiem Install Swift… — aktualizacje program sprawdza sam.

Motywy i skróty

Jasny i ciemny wygląd, motywy edytora, wybór czcionki i własne skróty klawiszowe — wszystko w ustawieniach (Ctrl+,).

Piszesz SwiftUI — iPhone od razu pokazuje efekt

Ten sam język i ten sam kod, co na Macu. Uczysz się Swifta na swoim komputerze z Windowsem, a gotowy projekt możesz później otworzyć w Xcode.

  • Prawdziwy kompilator Swift 6 ze swift.org — żadnych przeróbek języka.
  • Pliki jak w Xcode: Assets, Localizable, String Catalog, Info i ustawienia projektu.
  • Błędy w linii kodu i poprawki Fix-it, tak jak w Xcode.
  • Idealne do nauki i zadań z programowania iOS na studiach.
SCounterView.swift
import SwiftUI

struct CounterView: View {
    @State private var count = 0

    var body: some View {
        VStack(spacing: 24) {
            Text("\(count)")
                .font(.system(size: 96))
            Button("Dodaj") { count += 1 }
                .buttonStyle(.borderedProminent)
        }
    }
}

Start w kilka minut

Jak zacząć programować na iPhone'a na Windows

Trzy kroki — bez Maca, bez konta deweloperskiego i bez konfiguracji w terminalu.

Pobierz i zainstaluj

Uruchom WinSwift-Studio-Setup.exe i kliknij Dalej → Zainstaluj. Nie trzeba uprawnień administratora — skróty pojawią się na pulpicie i w menu Start.

Zainstaluj Swift jednym kliknięciem

Przy pierwszym uruchomieniu kliknij przycisk Install Swift… — program pobierze kompilator Swift i Visual Studio Build Tools (Windows raz zapyta o zgodę).

Nowy projekt → Ctrl+R

Create New Project → iOS → App i naciśnij Ctrl+R. Aplikacja uruchomi się w symulatorze iPhone'a (pierwszy raz trwa to 1–2 minuty).

Windows pokazuje „System Windows ochronił ten komputer”? Kliknij „Więcej informacji” → „Uruchom mimo to”. Program jest darmowy i nie ma płatnego certyfikatu podpisu, a jego kod jest publiczny na GitHubie.
